# YT Cluster 1.20.4

Published 2026-10-27. deb `yt-cluster` 1.20 (build 1.20.4), EL9 rpm 1.20.4, tgz 1.20.4,
Docker image `dbinvent/yt:1.20.4`. ytserv 1.20.4.

## Fixed

- Right after a release, the apt server's cache could keep serving the previous deb under
  the new index, so `apt install` failed with "Hash Sum mismatch". Every publish now
  refreshes the cached deb and its signature, and stops if it cannot.

## Tested

Nightly: 1,528 unit tests passed, 0 failed, with the release build. The full end-to-end
suites ran on the next build, 1.20.5.
