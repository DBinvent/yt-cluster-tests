# YT Cluster 1.20.3

Published 2026-10-26. deb `yt-cluster` 1.20 (build 1.20.3), EL9 rpm 1.20.3, tgz 1.20.3,
Docker image `dbinvent/yt:1.20.3`. ytserv 1.20.3.

## New

- Extension event triggers `yt_ddl_end` (ALTER TABLE), `yt_ddl_seq` (ALTER SEQUENCE,
  ALTER SCHEMA) and `yt_ddl_drop` (drops) tell ytserv to read sequences again. ytserv
  installs or updates them in each database it serves, at start and on registration, as
  members of the `yt_cluster` extension.

## Changed

- etcd's messages follow ytserv's language, taken from the system locale at start.
- Dependency ctutils updated to 0.4.4 (RUSTSEC-2026-0385).

## Fixed

- **Severe:** a party transaction rolled back while being parked or prepared could stay open
  holding its row locks, so later party changes timed out ("Fail to modify peer ...
  Timeout expired").
- A replicated insert moved another table's sequences, or none, where table oids differ
  between nodes, so a later local insert failed with a duplicate key. Sequences are now
  found by database, schema and table name.
- A gap no node holds a record of kept every synced table from writes until
  `recovery_auto_sec` (default 120 s). Its compare now runs after twice the longest table
  SQL timeout, never before two rounds of the leader's rollback grace (20 s by default), at
  most `recovery_auto_sec`; a gap still in flight waits the full `recovery_auto_sec`, and
  gaps of a lease run are left out. The rollback grace for a subterm no member holds is
  max(4 x `def_sql_timeout_sec`, 10 s).
