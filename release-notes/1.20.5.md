# YT Cluster 1.20.5

Published 2026-10-28. deb `yt-cluster` 1.20 (build 1.20.5), EL9 rpm 1.20.5, tgz 1.20.5,
Docker image `dbinvent/yt:1.20.5`. ytserv 1.20.5.

## New

- **Commit-mode guardrail:** a table placed by zone or shard may not use `cluster_commit`
  half or all. Such a config row is refused when written on this node (ytserv and ytctl),
  and taken when applied from another. Rows found breaking the rule raise a Warning alert in
  `yt_alert` (on the leader; linked clusters not counted), filed again while open and
  resolved when fixed. Shard tables are exempt from the alerts.
- Cluster setting `lang` (module C) sets the language of ytserv, etcd and sge messages; the
  database's `lc_messages` is read as well. Russian messages completed for ytserv and added
  for ytctl.
- A Critical alert (source `apply`) when the same subterm's SQL apply fails 3 times.
- A split under TLS can make the new cluster an upper (level=UPPER) or a neighbor
  (level=NEIGHBOR), not only a lower one. The old CA trust is dropped and revoked at the cut.

## Changed

- An exclusion constraint makes its whole table one boundary.
- A check-in that arrives while the WAL loads waits, up to the statement timeout, instead of
  failing at once.
- ytctl supports the PostgreSQL majors the extension is built for, 14 to 19 (was 10 to 20).

## Fixed

- **Severe:** a write could be lost - a subterm a member applied only in part could count as
  applied. Statements are now recorded as applied, and the subterm sealed, only when whole;
  a checkout no longer closes a subterm whose apply is in flight; an apply stopped by a
  restart resumes after its last recorded statement, with a Critical alert if it is not
  finished in 120 s. Found by the nightly tests.
- A pooled party connection kept its session settings (role, `yt.sync`, `yt.node`,
  `yt.jwt`) for the next user of the connection, so a later write could commit on one node
  only. They are now set per transaction (SET LOCAL).
- A subterm already trimmed below the cluster's least completed subterm was counted as a gap.
- The extension's in-trigger flag is cleared on a subtransaction abort and at every
  transaction end, so an error inside the trigger no longer leaves it set.

## Bundled

- rppd: Russian messages, the language from LC_ALL, LC_MESSAGES or LANG; the rate shaper
  dates its first bucket by the real start, so a late first start is not counted against it.

## Tested

Nightly: 4,613 tests passed, 0 failed, in 12 suites (Jepsen included).
