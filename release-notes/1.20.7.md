# YT Cluster 1.20.7

Published 2026-11-01. deb `yt-cluster` 1.20 (build 1.20.7), EL9 rpm 1.20.7, tgz 1.20.7,
Docker image `dbinvent/yt:1.20.7`. ytserv 1.20.7.

## New

- A Warning alert in `yt_alert`, once per table, when a table syncs by something other than
  its primary key: a table with no primary key, or a merge table with a unique key beside
  its primary key. Such tables are better not synced.
