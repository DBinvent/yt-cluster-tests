# YaXAHA Cluster 1.18.86

Published 2026-10-13, under the product's former name. deb `yaxaha` 1.18.86, EL9 rpm
1.18.86. ytserv 1.1.85.

## New

- C setting `sg_migration`: the schema gate judges a table whose shape differs between nodes
  by Schema Guard's migration rules, so a type change Schema Guard can amend is accepted. A
  differing table is checked again every 30 s.
- Recon compares table shapes: a peer whose table shape differs is skipped, and repair across
  different shapes is refused.

## Changed

- During a rolling schema change, writes to a table whose columns differ between nodes keep
  failing until the nodes agree. A member never drops a column it lacks: column drops go
  through explicit Schema Guard scripts.

## Fixed

- After `ALTER TABLE ... DROP COLUMN` the extension still counted the dropped column in the
  rows it sent; inserts, updates and deletes now skip it.
- The unused peer calls `whole` and `mutate` are removed; their stubs aborted ytserv if
  called.
- A WAL page dropped from memory is read back from its place in the file.

## Bundled

- Schema Guard takes its migration options from the cluster's `sg_migration`.
