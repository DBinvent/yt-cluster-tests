# YT Cluster 1.20.12

Published 2026-11-06. deb `yt-cluster` 1.20 (build 1.20.12), EL9 rpm 1.20.12, tgz 1.20.12,
Docker image `dbinvent/yt:1.20.12` (also `1.20` and `latest`). ytserv 1.20.12.

## Fixed

- **Warning:** linked clusters - a lower cluster could fail to sign in to its upper cluster
  right after the upper rotated its master key. The two clusters number their key versions
  separately, so the lower named a version the upper also held and got a certificate it
  could not trust yet; it receives the upper's new root only by signing in. The upper then
  kept its old key, waiting for the lower. Now, when a node cannot trust the certificate a
  peer answered with, it tries each of its own versions again without naming one, newest
  first, and gets the peer's oldest live certificate, which every peer still trusts.
